# Нові фото

1. Відкрийте цю папку `photos_in` на GitHub → **Add file** → **Upload files**.
2. Перетягніть **папку** з назвою як Realting ID об'єкта: `GFC-CAPRI`, `GFC-KOSMOS`, `GFC-3843771` … (усередині – jpg/png/webp, до 25 МБ кожне, до 100 файлів за раз).
3. Унизу виберіть **Commit directly to the main branch** → **Commit changes**.

Робот сам перетворить фото на JPEG (до 2048 px), покладе їх у `images/GFC-…/` з наступними номерами (07.jpg, 08.jpg …),
видалить їх звідси й оновить фіди. Нові фото стають у кінець галереї – щоб змінити порядок, впишіть їх у вкладку «Фото» таблиці.
Фото, у яких менша сторона < 600 px, Prian не приймає – вони пропускаються.
